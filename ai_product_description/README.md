# AI Product Description Generator

Automatically generate professional product descriptions using OpenAI's GPT models.

## Features

- **One-Click Generation**: Add AI-generated descriptions with a single button click
- **Multiple Templates**: Choose from Brief (50 words), Standard (100 words), or Detailed (200 words)
- **Preview & Edit**: Review and modify descriptions before saving
- **Secure Configuration**: API key stored securely in Odoo settings
- **Error Handling**: Clear feedback for API issues, invalid keys, or quota limits

## Requirements

- Odoo 19.0+
- OpenAI API key (create one at [platform.openai.com](https://platform.openai.com))
- Python package: `openai` (included in dependencies)

## Installation

1. Download and extract the module to your `addons` directory
2. Update the app list in Odoo
3. Install "AI Product Description Generator"
4. Configure your OpenAI API key in Settings → General Settings → AI Product Description

## Cost

## Usage

1. Open any product form
2. Click the "Generate with AI" button
3. Select a template (Brief, Standard, or Detailed)
4. Preview the generated description
5. Edit if needed
6. Click "Use This Description" to save
